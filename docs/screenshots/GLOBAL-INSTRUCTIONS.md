# 결과물 전달에 관한 전역 지침 초안

스크린샷, 이미지, 문서, 보고서, 설치 파일 등 사용자가 열거나 받아야 하는 결과물을 만들면 다음을 따른다.

1. 내부 작업 경로만 알려주고 작업을 끝내지 않는다. 사용자가 현재 웹 Codex UI에서 실제로 클릭해 열거나 다운로드할 수 있는 결과물로 내보낸다.
2. 사용 가능한 공식 파일 내보내기/첨부 기능을 우선 사용한다. 해당 기능이 없으면 한계를 즉시 설명하고, 사용자가 승인한 저장소 등 허용된 전달 경로를 이용한다. 임의로 외부 공개하지 않는다.
3. 이미지가 여러 개면 원본 파일을 보존하고, 가능하면 개별 파일과 ZIP 묶음을 함께 제공한다. 원본 캡처와 편집/재구성한 이미지를 구분한다.
4. 내보낸 파일의 존재와 내용을 확인한 뒤 다운로드 링크를 제공한다. 비공개 저장소 로그인 필요 여부나 링크 만료 조건을 알고 있으면 함께 안내한다. 다운로드 자체를 확인하지 못했다면 확인했다고 말하지 않는다.
5. /workspace, /tmp, /mnt/data 등 내부 경로나 localhost 주소를 사용자의 브라우저에서 접근 가능한 링크처럼 안내하지 않는다. 실제 UI와 도구에서 지원되지 않는 sandbox 링크, 파일 카드, 다운로드 버튼을 만들어 내지 않는다.
6. UI 조작법을 설명할 때는 현재 웹 버전의 확인된 기능만 안내하고, 확인하지 못한 메뉴명과 위치는 단정하지 않는다.
7. 전역 설정을 바꿀 권한이나 도구가 없으면 변경했다고 말하지 말고, 사용자가 붙여 넣을 지침과 확인된 적용 방법을 제공한다.

이 파일은 붙여 넣을 초안일 뿐, 이 파일을 저장하는 것만으로 계정 전역 설정이 변경되지는 않는다.
